Vidéothèque TikTok

Tes favoris et tes vidéos aimées, cherchables par légende, hashtag ou créateur. Tout reste dans ton navigateur.

Dépose ton fichier ici
Accepte l’export TikTok (user_data_tiktok.json ou le .zip) et le fichier enrichi tiktok_enrichi.json. Les imports s’additionnent.

Légendes à récupérer
Obtenir son export TikTok
  1. TikTok → Profil → ☰ → Paramètres → Compte → Télécharger tes données → format JSON. Le fichier arrive en général en quelques heures à quelques jours.
  2. Dépose le fichier (ou le .zip) dans cette page.
  3. Clique sur Récupérer les légendes. Le serveur interroge TikTok par lots ; tu peux fermer la page et reprendre plus tard, le progrès est gardé.

Les vidéos supprimées ou devenues privées restent listées avec leur date, sans légende. La bibliothèque est gardée dans ce navigateur seulement : utilise « Sauvegarder » pour la transférer sur un autre appareil.
